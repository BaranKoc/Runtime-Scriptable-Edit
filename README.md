# Runtime Scriptable Edit

This repository contains the source code for the **Runtime Scriptable Edit** Unity package. This is an Editor-only tool designed to help you modify ScriptableObjects during runtime.

## 📖 Documentation
For detailed instructions and setup information, please refer to the documentation included in this repository:
* **[RuntimeScriptableEdit_Documentation.pdf](./RuntimeScriptableEdit_Documentation.pdf)**

## ⚙️ Manual Download & Installation 
To install this tool manually, you must place the files in a specific directory so Unity recognizes it as an Editor tool:

1. **Download** or clone this repository to your computer.
2. **Drag and drop** the downloaded folder into your Unity project. 
3. **Crucial Step:** Because this is an Editor script package, it *must* be placed inside an `Editor` folder within your Assets. The exact path should look like this:
   * `Assets/Editor/RuntimeScriptableEdit/` 
   *(If you don't have an `Editor` folder inside your `Assets` folder, create one first).*
4. Allow Unity a moment to compile the scripts, and the tool will be ready to use.
